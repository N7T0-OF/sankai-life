# Classiques français — pack d'exemple

Ce dossier est la forme source d'un paquet culturel Sankai. Pour l'importer,
placer `pack.json`, `entries.json`, `README.md` et `LICENSE` à la racine d'une
archive ZIP, puis lui donner l'extension choisie par l'interface d'import.

Le pack ne contient que du texte et des métadonnées. Il n'embarque aucun code,
script, HTML, police ni média actif. Les trois textes proviennent d'auteurs
morts depuis largement plus de 70 ans et sont signalés `PUBLIC_DOMAIN`.

Sources consultables :

- Victor Hugo, *Les Contemplations*, « Demain, dès l'aube… », Wikisource ;
- Joachim du Bellay, *Les Regrets*, sonnet XXXI, Wikisource ;
- Blaise Pascal, *Pensées*, fragment 277 selon Brunschvicg, Wikisource.

Les URL exactes et le contexte sont conservés dans chaque entrée. Une future
mise à jour d'un texte doit aussi mettre à jour son empreinte dans `pack.json`.
